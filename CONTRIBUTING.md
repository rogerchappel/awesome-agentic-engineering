# Contributing

Thanks for helping make this map more useful.

## Good entries

A strong entry should:

- Help people build, review, test, observe, or govern software work done with coding agents.
- Link to stable public documentation, a repository, or a product page.
- Have an original one-sentence description explaining the practical engineering use case.
- Fit one existing category, or justify a new category in the pull request.
- Avoid hype, affiliate links, ranking language, and vague claims.

## Pull request checklist

1. Edit `data/resources.json` only. The README is generated.
2. Run `npm run build`.
3. Run `npm run check` and `npm test`.
4. Include why the resource belongs here and what category it improves.

## Curation boundaries

This is not a general AI tools directory. It focuses on agentic engineering: coding agents, agent frameworks, context protocols, verification, safety, and operator workflows for software teams.

Roger's own tools may be included when they are relevant, but they should be held to the same usefulness bar as third-party projects.
